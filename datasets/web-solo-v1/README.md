# Web-only solo experiment

This is the exact source snapshot and generated export used in the first run of the [solo workflow](../../docs/solo-web-training.md). It is separate from the original pilot and the earlier source-linked experiment.

- `corpus/`: 57 documents and 598 chunks from 48 AOSA chapters and nine pinned System Design Primer pages, with hashes, source configuration, licenses and a crawl audit.
- `export/cases.jsonl`: 30 machine-authored hypothetical cases from ten accepted source documents. These are not observed failures, company guarantees or human-reviewed verdicts.
- `export/*.jsonl`: 18 train, six development, three calibration and three untouched test examples in Laya format.
- `export/rejections.json`: 14 candidate documents whose selected passage was rejected as irrelevant to its assigned decision.
- [Measured results](../../docs/web-training-results.json): one CPU epoch, frozen encoder, approximately 15M trainable parameters. Development label agreement remained 2/6 before and after training.

The development set covers retry safety and queue overload. The calibration set contains only acknowledgement durability. These tiny, uneven splits cannot establish reliable model quality or calibration. Rules gate the generated labels, so rule agreement is a construction check, not an independent evaluation result. No old pilot examples or runtime evidence were used in this run; underlying source topics can overlap previous experiments.

The snapshot is kept unchanged so its hashes match the measured experiment.

## Reuse this exact export

From the repository root, with the model environment installed:

```powershell
.\.venv\Scripts\python.exe scripts\finetune_web.py --data datasets\web-solo-v1\export --base models\laya-multilingual --output models\web-head-reproduction --epochs 1
```

Use the actual location of your existing base checkpoint. The initial experiment used upstream revision `1720e3e3357cfe1e281542e223f8273b0890ca34`; the results report records its weights hash. No model weights, account credentials or private host logs are included here.
